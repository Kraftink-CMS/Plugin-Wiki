# Wiki for KraftInk

Create a searchable knowledge base for your server with guides, rules and other reference pages. Group pages in nested categories and choose which sections visitors, members or selected ranks can access.

Install Wiki from **Plugins** in the KraftInk admin panel, then open **Extensions → Wiki**.
